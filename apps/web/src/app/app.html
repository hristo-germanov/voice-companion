Automatic reading

Choose whether replies, prompts, or both are read aloud. Captured messages are saved below.

How does ChatGPT listening work?

Keep Voice Companion running while you use ChatGPT in Chrome or Edge. The extension sends messages here; the switches above control which messages are read automatically.

One-time setup

  1. Open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select the apps/extension folder.
  2. Open the extension's Options. Set Backend Port to 17832 and API Key to the Api:ApiKey value in your local apps/api/appsettings.json.
  3. Enable capture, select Save, and refresh your ChatGPT tab.

While chatting

Send a message in ChatGPT. Captured messages appear below, and enabled replies are added to the playback queue once their text stops changing. Use Play now to switch to a saved message, or Add to queue to listen later.

Visible messages may also be captured when you open a conversation. Turn off capture in the extension to stop sending messages here; the reading switches only control automatic audio.

No messages arriving? Check that the extension is enabled, confirm its port and API key, then refresh the ChatGPT tab.
